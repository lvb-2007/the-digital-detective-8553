### Task 1.1 — IPOS trace
Activity chosen: typing and saving a note in VS Code.

| Stage | What happens in my example | Hardware / component |

| Input | I press keys and each key press is sent to the computer as a signal | Keyboard |
| Processing | The CPU works out which character each key stands for and runs the editor program. RAM holds the text while I work | CPU, RAM |
| Output | The letters appear on the screen as I type | Screen (display) |
| Storage | When I press Cmd+S, the file is written to the drive and stays after shutdown | SSD |

The activity starts when I press a key on the keyboard (input). The signal
goes to the CPU, which processes it, and RAM holds the text temporarily while
I work. The result shows on the screen straight away (output). The text is
only kept permanently when I save it, because that writes it to the SSD
(storage). If the power went off before saving, the text in RAM would be lost.
