4. `git status` — Checked the working tree and pending changes.
5. `git log --oneline` — Reviewed the commit history.
6. `git branch -a` — Checked local and remote branches.
7. `git remote -v` — Verified the connected GitHub repository.
8. `git add .` — Staged the required final changes.
9. `git commit -m "docs: complete final report and verify assignment submission"` — Committed the final documentation.
10. `git push` — Pushed the final changes to GitHub.
